# Backlog

Problems found while working on another task, not fixed there to keep that task's scope.
An entry is not a plan: when someone takes it, `/task` reads the entry and the code as it is then, and writes
the plan in `plans/tasks/`. Remove the entry when its task starts; the plan links back to it.

Every entry has:
- **What**: the problem and where it lives.
- **Why not now**: why it was left out (cost, risk, no consumer yet).
- **Trigger**: the event that makes it worth doing. Without one an entry is just noise.
- **Context**: the plan, decision or file where it came up.
